TOSSADDA deployment preparation

This package excludes node_modules, .env, and SQLite database files. Never upload your .env or bot token to GitHub.

Render can run this Node/Express app, but its free service filesystem is ephemeral. This config uses /tmp only to make that limitation explicit: user accounts, points, and matches may reset after restart/redeploy. Do not use for a real persistent public launch until the SQLite database is migrated to a persistent hosted database.

Required Render environment variables: ADMIN_EMAIL and ADMIN_PASSWORD (set privately in Render dashboard). JWT_SECRET is generated by Render. Add Telegram variables only if you intentionally configure Telegram.
